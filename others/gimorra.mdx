Give it an **authorized** target, a goal and a scope. It takes the engagement from there — **recon → scan → propose a PoC → prove it → report** — and wakes you only when blast radius demands a human.

Vigolium is the engine. Gimorra is the operator.

## Safety by construction, not by babysitting

Most offensive agents ask a human to approve every action. That is not caution — it is an admission that the agent could do real damage if nobody is watching.

Gimorra closes that gap in code. Three controls make a run **incapable** of hurting the target, so supervision becomes a dial you set once instead of a seat you sit in.

<Columns cols={3}>
  <Card title="The validator decides" icon="circle-check">
    The agent proposes. Code disposes. Every finding is re-proven by deterministic, non-AI code using the least invasive action that settles it. **Nothing self-certifies.**
  </Card>
  <Card title="Cleanup and a kill switch" icon="power-off">
    Whatever a run touches, it puts back. One command ends the engagement: queued work goes unclaimable, and no further proof is accepted.
  </Card>
  <Card title="Scope guard on every call" icon="shield-halved">
    Deny wins. Ambiguity blocks. Checked on every single tool call, before anything else gets a vote.
  </Card>
</Columns>

None of the three touches the model, the agent, or the network stack. **Prompt-inject the model and they still hold.** That is the whole design.

<Warning>
  Gimorra operates only against targets you are authorized to test. **No authorization artifact, no active operation** — enforced in code, not in policy.
</Warning>

## Point it at anything

| Give it | Get back |
|---|---|
| A URL, host, domain, IP or CIDR | A scoped, authorized engagement — mapped, tested, and the real bugs proven |
| A sentence of plain English | The same run, aimed where you said: *"focus on IDOR and broken access control"* |
| An API spec or a captured session | Every documented operation turned into testable surface before a packet moves |
| A repository or a shipped app bundle | A source audit, beside the live target or on its own |
| A full bug-bounty scope document | Every in-scope asset, worked as one engagement |

One dial sets how hard it pushes, from fully passive to aggressive. Nothing else needs tuning to get a first result.
